# 📊 Retail Sales Dashboard & Sales Forecast (Power BI)

## 📌 Project Overview

This project is an interactive Power BI dashboard built using the Superstore Retail Sales dataset. It provides business insights into sales, profit, customer performance, product categories, regional sales, and future sales forecasting through interactive visualizations.

---

## 📸 Dashboard Preview

![Retail Sales Dashboard](DashboardpowerBI.png)

---

## 🎯 Objective

The objective of this project is to analyze retail sales data and build an interactive dashboard that helps businesses monitor performance, identify trends, and support data-driven decision-making.

- Data Visualization

## 📈 Dashboard Features

- Total Sales
- Total Profit
- Total Orders
- Sales by Category
- Sales by Region
- Customer Analysis
- Monthly Sales Trend
- Interactive Filters (Slicers)
- Sales Forecasting
